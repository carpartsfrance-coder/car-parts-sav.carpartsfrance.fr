# Nouveau document (exemple)

Bienvenue dans le Centre de formation SAV.

- Utilisez la barre de recherche (en haut) pour trouver rapidement un guide.
- Parcourez l’arborescence à gauche (Guides, Transport, Garantie, etc.).
- Un sommaire automatique apparaît en haut du document.

## Bonnes pratiques

- Toujours vérifier la commande et les coordonnées avant toute action.
- Documenter chaque étape (note interne) et utiliser les modèles fournis.
